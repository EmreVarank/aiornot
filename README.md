## What Is This?

AI Checker is a web application that analyzes text to determine whether it was written by a human, generated by an AI model, or is a mix of both. It combines **6 heuristic linguistic metrics** with **Google Gemini LLM verification** to produce accurate, sentence-level results.

No signup. No data retention. Results in under 3 seconds.

---

## Features

- **Hybrid Detection Engine** — heuristic analysis runs instantly while LLM verification cross-checks for generative fingerprints
- **Sentence-level highlighting** — see exactly which sentences are AI-generated (red), uncertain (amber), or human-written (green)
- **6 Linguistic Metrics** — Uniformity, Vocabulary, Burstiness, AI Patterns, Coherence, Naturalness
- **Document Upload** — supports PDF and DOCX (up to 10MB, extracted client-side)
- **Dark / Light theme** — persisted to localStorage
- **Zero data retention** — text is analyzed in memory and immediately discarded
- **Rate limiting** — 10 analyses/min per IP, 100 requests/15min global
- **Privacy-first** — no tracking, no cookies beyond theme preference

### Detects content from:
`ChatGPT / GPT-4o` · `Claude 4` · `Gemini 2.5` · `Llama 4` · `Mistral` · `DeepSeek` · `Copilot` · `Jasper`

## Getting Started

### Prerequisites

- Node.js 18+
- A [Google Gemini API key](https://aistudio.google.com/app/apikey) (free tier available)

### Installation

```bash
# Clone the repository
git clone https://github.com/EmreVarank/aiornot.git
cd aiornot

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
```

Edit `.env` and add your Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
NODE_ENV=production
```

### Run

```bash
# Development (with file watching)
npm run dev

# Production
npm start
```

Open `http://localhost:3000`

## How the Detection Works

### 1. Heuristic Analysis (client-side, instant)

Six metrics are computed locally in the browser:

| Metric | What it measures |
|--------|-----------------|
| **Uniformity** | Coefficient of variation in sentence lengths — AI tends to be uniform |
| **Vocabulary** | MATTR score (moving average type-token ratio) + hapax ratio |
| **Burstiness** | Variation in sentence complexity — humans are more "bursty" |
| **AI Patterns** | Density of 44 weighted AI cliché phrases (e.g. "it's worth noting") |
| **Coherence** | Paragraph length consistency and topic sentence patterns |
| **Naturalness** | Contraction rate, first-person usage, questions/exclamations |

### 2. LLM Verification (server-side, via Gemini)

The server proxies the text to Google Gemini 2.5 Flash, which returns:
- Overall verdict (`ai` / `human` / `mixed`)
- Confidence score (0–100)
- Per-sentence labels and confidence

### 3. Result Fusion

When the API succeeds, sentence highlights come directly from Gemini's labels. If the API fails or times out, the heuristic scores are used as fallback. The user always gets a result.

## API Endpoint

### `POST /api/analyze`

**Request:**
```json
{
  "text": "Your text here (50–20,000 characters)"
}
```

**Response:**
```json
{
  "verdict": "ai",
  "confidence": 87,
  "reasoning": "The text exhibits uniform sentence lengths...",
  "sentences": [
    { "text": "First sentence.", "label": "ai", "confidence": 92 },
    { "text": "Second sentence.", "label": "human", "confidence": 74 }
  ]
}
```

**Rate limits:** 10 requests/min per IP on this endpoint.

**Health check:** `GET /health` → `{ "status": "ok", "ts": 1234567890 }`

## Deployment

### Render (recommended)

1. Connect your GitHub repo on [render.com](https://render.com)
2. Create a new **Web Service**
3. Set build command: `npm install`
4. Set start command: `npm start`
5. Add environment variable: `GEMINI_API_KEY`
6. Deploy

### Railway

```bash
railway login
railway init
railway add
railway deploy
```

Set `GEMINI_API_KEY` in the Railway dashboard.

### Heroku

```bash
heroku create your-app-name
heroku config:set GEMINI_API_KEY=your_key
git push heroku main
```

The included `Procfile` handles process configuration automatically.

## Security

- **Helmet.js** — sets Content Security Policy, HSTS, and other security headers
- **Rate limiting** — prevents abuse on the analysis endpoint
- **Input validation** — text length enforced server-side (50–20,000 chars)
- **No API key exposure** — Gemini API key never reaches the browser
- **Zero retention** — analyzed text is never stored
